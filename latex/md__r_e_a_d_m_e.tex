This project is a C++ console application for projecting the growth of an investment over a user-\/selected number of years. It was developed for the SNHU CS-\/210 Project Two assignment.

The application accepts an initial investment, a recurring monthly deposit, an annual interest rate, and an investment duration. It then prints monthly balance tables for:


\begin{DoxyEnumerate}
\item Growth without additional monthly deposits.
\item Growth with the configured monthly deposit.
\end{DoxyEnumerate}

Each report includes the month, opening amount, deposited amount, total before interest, interest earned, and closing balance.\hypertarget{md__r_e_a_d_m_e_autotoc_md1}{}\doxysection{\texorpdfstring{Requirements}{Requirements}}\label{md__r_e_a_d_m_e_autotoc_md1}

\begin{DoxyItemize}
\item A C++ compiler with C++20 support
\item GNU Make (for the Makefile workflow)
\item Doxygen (only required to regenerate the API documentation)
\end{DoxyItemize}

The project also includes a Visual Studio project file, \href{./BankingApp.vcxproj}{\texttt{{\ttfamily Banking\+App.\+vcxproj}}}, configured for C++20.\hypertarget{md__r_e_a_d_m_e_autotoc_md2}{}\doxysection{\texorpdfstring{Building and running}{Building and running}}\label{md__r_e_a_d_m_e_autotoc_md2}

On Windows, open {\ttfamily Banking\+App.\+slnx} or {\ttfamily Banking\+App.\+vcxproj} in Visual Studio and build the desired configuration.\hypertarget{md__r_e_a_d_m_e_autotoc_md4}{}\doxysection{\texorpdfstring{Using the application}{Using the application}}\label{md__r_e_a_d_m_e_autotoc_md4}
When the program starts, enter the following values when prompted:


\begin{DoxyTable}{3}{}{}{1}
\SetCell{c,bg=\tableheadbgcolor,font=\bfseries}Input  &\SetCell{c,bg=\tableheadbgcolor,font=\bfseries}Description  &\SetCell{c,bg=\tableheadbgcolor,font=\bfseries}Accepted values  \\
Initial investment  &Starting balance  &At least {\ttfamily 1.\+0}  \\
Monthly deposit  &Amount added each month in the deposit report  &At least {\ttfamily 1.\+0}  \\
Interest rate  &Annual interest rate, entered as a percentage  &At least {\ttfamily 1.\+0}  \\
Number of years  &Projection length  &At least {\ttfamily 1}  \\
\end{DoxyTable}


Input is read and validated as complete lines. The program continues prompting until each value is numeric, contains no trailing characters, and meets its minimum value.

After the input summary is displayed, press {\bfseries{Enter}} to generate the reports. Press {\bfseries{Enter}} at the final prompt to exit.\hypertarget{md__r_e_a_d_m_e_autotoc_md5}{}\doxysection{\texorpdfstring{Calculation model}{Calculation model}}\label{md__r_e_a_d_m_e_autotoc_md5}
The annual interest rate is converted to a monthly decimal rate:


\begin{DoxyCode}{0}
\DoxyCodeLine{monthly\ rate\ =\ annual\ rate\ /\ 100\ /\ 12}

\end{DoxyCode}


For every month, the application:


\begin{DoxyEnumerate}
\item Uses the previous month\textquotesingle{}s closing balance as the opening balance.
\item Adds the monthly deposit when generating the deposit report.
\item Calculates interest on the resulting total.
\item Adds the interest to produce the closing balance.
\end{DoxyEnumerate}

The report values are displayed with two decimal places. The calculation continues from the unrounded internal {\ttfamily double} values.\hypertarget{md__r_e_a_d_m_e_autotoc_md6}{}\doxysection{\texorpdfstring{Project structure}{Project structure}}\label{md__r_e_a_d_m_e_autotoc_md6}
